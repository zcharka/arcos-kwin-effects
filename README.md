# arcos-kwin-effects

## EN

This package set things in plasma desktop:
- Kwin effects (glass and rounded-corners)
- Set transparency in apps (konsole etc)
- Install effect again after KWin updates

### Dependencies:
- kwin
- kwin-effects-glass-git
- kwin-effect-rounded-corners-git
- git
- cmake
- gcc
- make

## PL

Ta paczkla ustawia rzeczy w pulpicie plasma
- efekty Kwina (glass i rounded-corners)
- Ustawia przeźroczyustość w programach (konsole i inne)
- Instaluje ponownie efekty po aktualizacji KWina

### Zależności:
